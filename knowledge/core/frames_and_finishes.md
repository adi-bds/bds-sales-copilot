## MODULE 1 — BASICS

### 1. Banner Finishes

Different finishes are used based on how the banner will be fixed. If an order does not specify a finish, hemming is done by default.

| Finish | Description | Common Use |
|--------|-------------|------------|
| **Pole Pockets** | Folded and stitched edges creating a sleeve for a pipe or rod. Standard size: 2.7–3 inches (can be customised). | Backdrop stands, hanging banners |
| **Eyelets (Grommets)** | Metal rings on the edges, 0.55 inch rounds. Used for tying with ropes or hooks. For very windy locations, offer **reinforced eyelets** (more durable). | Outdoor banners |
| **Velcro Finishing** | Stitched Velcro strips — 2 inch strip. Allows quick fixing and removal. Velcro has adhesive backing so can also attach banners to any surface. | Pop-up displays, attaching banners to surfaces |
| **SEG Finishing** | Silicone strip on the edges that fits into frame grooves. Can be done on any type of fabric. Gives a tight, premium finish. | SEG frames, lightboxes |
| **Hemming** | Folding and stitching the edges. Adds strength and durability. Used when the customer does not want any other finish — also the default if nothing is specified. | General use |
| **Pillowcase (Zipper)** | Like a cover with a zipper. Banner slides over the frame. Gives a clean, stretched look. | Tension fabric media walls |

**Additional custom finishing options:** zippers, ties, buttons, drawstrings, etc. — can be purchased and stitched, customised to the customer's needs.

### 2. Frame Types

Frame types are different structures used to support banners and displays. Each type is designed for a specific use and setup style.

| Frame Type | Description | Key Specs | Common Use |
|------------|-------------|-----------|------------|
| **Tubular Frames** | Round aluminum pipes — 32mm and 43mm diameter. 32mm for smaller sizes; 43mm required for anything over 6m wide (stability). | 32mm (standard), 43mm (6m+ width) | Tension fabric walls, booths, arches |
| **Popup Frames** | Box-like structures. Each unit (cube) is ~2.5ft. Cubes combine to create larger designs. Two types: SEG Popup (uses SEG fabric) and Fabric Popup (uses Velcro only). Max: 6m wide × 2.3m high. Min: 1.5m wide × 2.3m high. | ~2.5ft per cube unit | Pop-up banners, modular displays |
| **Aluminum Profiles** | Flat structure (not round pipes). Only SEG fabric can be used — fabric is tucked into grooves. | Flat profile | Premium walls, lightboxes |
| **Truss Frames** | Strong structure with a clean, premium look. Can hold lights and big banners. If a client already has a truss structure, BDS can supply truss banners designed to fit using appropriate finishing (eyelets or SEG). | Large scale | Large setups, stage use |
| **Roller Banners** | Retractable systems. Banner rolls inside a base unit. Easy to carry and set up. **Cannot be customised** — only available standard sizes. | — | Portable, indoor use |
| **Hexagonal Frames** | Six-sided tube shapes. Provide better strength and wind resistance. | — | Outdoor canopy tents |

### 3. Fabric Thickness (GSM)

GSM = grams per square meter. Higher GSM = thicker and stronger fabric.

| Fabric | Properties | Thickness / Material |
|--------|------------|----------------------|
| **Flag fabric** | Lightweight and flexible | Knitted polyester — **110 GSM** |
| **Blockout fabric** | Thick, does not let light pass | **300 GSM** |
| **Air mesh fabric** | Light and breathable | **130 GSM** |
| **Barrier fabric** | Medium thickness, used for crowd control banners | **260 GSM** |
| **Media wall fabric** | Smooth and stretchable, used in tension displays | **260 GSM** |
| **Canopy fabric** | Strong and weather-resistant | **600D PU polyester** — NOT polyester mesh. Do not quote 130 GSM for canopy tents. |
| **Inflatable fabric** | Very strong | 600D Oxford fabric |

## MODULE 2 — BACKDROP FRAMES (STUDY SHEET)

Backdrop frames are structures used to support banners, fabrics, or branding displays. They act as the base that holds the graphic in place, giving it shape, stability, and proper visibility.

---

### 1. Adjustable Backdrop Stands (Heavy-Duty Telescopic)

**Concept:** Uses a telescopic pipe system — pipes slide into each other to adjust size.

**Product name:** Backdrop with Adjustable Stand — fabric backdrop media wall with adjustable telescopic stand.

**Structure & Build:**
- Telescopic crossbars and vertical uprights
- Tiered pipe design for smooth adjustment
- Tube diameter: up to 2 inches (50mm)

**Size Range:**
- Width: 6ft (min) → 10ft (max)
- Height: 4ft (min) → 8ft (max)

**Bases:**
- Standard base
- Heavy base (same dimensions, added stability)

---

### Full Coverage Seamless Graphic Wall — Velcro Fixing

**How velcro works for a full coverage seamless graphic wall (e.g. shell scheme):**
- **Loop velcro** is stitched onto the print/graphic
- **Hook velcro** (adhesive-backed roll) is attached to the shell scheme structure/wall by the client
- The graphic is then pressed on top — it attaches firmly and can be removed and repositioned
- For exact velcro placement and fixing guidance for a specific wall setup, confirm with **Idris, Kaviya, Jennifer, or Areefa**

**Concept:** Fabric is stretched tightly over a fixed frame, creating a smooth, wrinkle-free surface.

### 3. Portable Straight Fabric Pop-Up Wall

**Concept:** A collapsible frame system that expands instantly using a pop-up mechanism.

**Finishing:** Velcro — commonly used, can be customised.

**How the graphic attaches:**
- **Loop velcro** is stitched directly onto the print/fabric
- **Hook velcro** (adhesive-backed roll) is attached to the pop-up frame structure
- The print is then pressed onto the frame — loop side on print, hook side on frame

**Structure:**
- Aluminum frame with scissor-style pop-up design
- Expands by pulling → locks into shape
- Fabric attaches using Velcro

**Tube Specification:** 0.66 inch diameter

**Assembly:** Tool-free setup (Pull → expand → lock)

---

### 4. SEG Pop-Up Wall

**What it is:** A premium display system that combines a pop-up frame structure with SEG fabric finish. Gives a clean, seamless, professional look.

**Structure:**
- Collapsible pop-up frame (easy to expand)
- Fabric has silicone edges (SEG)
- Fabric fits into frame grooves for a tight finish
- Frame type: Pop-up collapsible aluminum frame

**Assembly:** Tool-free — Pull frame → lock structure → insert SEG edges into frame grooves

**Example Products:**
- Backlit SEG Pop-Up Straight Display — $694
- SEG Popup Straight Media Wall — $585
- SEG Popup - Internal Showcase with Recessed LED Ring — $795

### 5. SEG Media Walls (Premium Finish System)

**What it is:** A clean, modern display where fabric edges are tucked into a flat aluminum frame (profile). No round pipes.

**What's different:**
